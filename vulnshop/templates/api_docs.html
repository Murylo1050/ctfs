API da VulnShop

Integração para consulta de pedidos por aplicativos parceiros.

Autenticação

Envie a chave da sua conta no cabeçalho X-API-Key. A chave também pode ser passada pelo parâmetro api_key.

A chave da conta demo neste ambiente é:

{{ demo_key }}

Consultar pedido

GET /api/v1/orders/<id>

Retorna status, itens, dados de entrega, observações do cliente e a nota interna do pedido. 

curl -s \
  -H "X-API-Key: {{ demo_key }}" \
  http://localhost:8012/api/v1/orders/1002

Exemplo de resposta

{
  "id": 1002,
  "status": "Em trânsito",
  "total": 329.9,
  "owner": {
    "username": "demo",
    "email": "demo@vulnshop.local"
  },
  "items": [
    {
      "name": "Teclado Mecânico K2",
      "unit_price": 329.9,
      "quantity": 1
    }
  ],
  "customer_note": "...",
  "internal_note": "..."
}

A documentação é pública. As chaves são individuais e aparecem na página Minha conta.
